                        Send to Kindle over USB

                        KoShelf converts your EPUBs on this computer into AZW3 copies for the Kindle reader. Your original EPUBs stay in your library.

                        The converter runs without a sandbox on this system. KoShelf can only sandbox it on macOS so far; Linux sandboxing is on the roadmap. The converter can read and write your files and use the network while it runs, so only convert EPUBs you trust.

                            Reader fonts

                            How to install and use fonts
                            1. Connect your Kindle by USB. If you downloaded a ZIP, unzip it first.
                            2. Choose a destination and add the TTF, OTF, or TTC files. Install regular, italic, bold, and bold italic together when available. Static styles are a good starting point.
                            3. Eject the Kindle and open a book. Choose Aa → Font in the Kindle reader or Font in KOReader’s top menu. Restart KOReader if it was already open.

                            Removing a font saves a copy on this Mac in KoShelf’s removed-fonts state folder. You can import that copy again. Bundled KOReader fonts are marked in the list.
