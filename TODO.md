# KoShelf roadmap

1. [x] **Bulk metadata editing.** Select books from the shelf or a filtered view. Review and apply shared author or genre changes, with a verified backup for each edited EPUB. Move selected books into an existing folder or create one for them.
2. [x] **One sync review.** Show transfers in both directions, moved books, and conflicts in a single review before making changes.
3. [x] **KOReader reading status.** Read status and progress from KOReader’s saved data when available. Show it on the shelf and add status filters.
4. [x] **Duplicate finder.** Show exact copies across folders and flag possible matches by title and author for review.
5. [x] **Drag-and-drop imports.** Drop EPUBs from Finder into a library folder. Preview the destination and check for duplicates and filename collisions before copying.
6. [x] **Series and reading order.** Read and edit series names and book numbers, group titles by series, and sort by reading order.
7. [x] **Cover art editing.** Preview and replace an EPUB's embedded cover with an image you choose.
8. [ ] **Sync with the Records project.** Identify which book and reading records to share and decide how updates should flow between the projects.
9. [x] **Automatic genre and title cleanup.** Preview and approve offline suggestions in the Mac library.
    - [x] Offline genre preview with editable tag mappings.
    - [x] Apply approved genre changes with verified EPUB backups.
    - [x] Suggest removing title suffixes that match the embedded series and book number.
10. [x] **Sync history and undo.** Review EPUB copies, moves, replacements, and archives recorded by each sync. Undo individual changes from the history.
11. [x] **Library health check.** Review unreadable metadata, missing covers and authors, and incomplete or inconsistent tags and series fields. Open books directly from the report.
12. [ ] **Author and award-tag cleanup.** Suggest author aliases and cleanup of award labels.
13. [ ] **iCloud Drive and Kindle sync.** Review changes across all three libraries in one run.
    - [x] Review and sync changes between Mac and iCloud Drive, with recovery copies and history.
    - [ ] Include the connected Kindle in the same review and verify the iPhone-to-Kindle workflow.
14. [x] **Kindle font utility.** Preview installed font families and import TTF, OTF, and TTC files for the Kindle reader, KOReader, or both. Check for duplicate files and save a recovery copy when removing a font.
15. **Stock Kindle delivery.**
    - [x] Convert Mac-library EPUBs to AZW3 and send over USB to Kindles that mount as drives.
    - [x] Detect KOReader over USB and bundle an AZW3 converter for the Kindle reader.
    - [ ] Explore USB delivery to models that use MTP on macOS.
