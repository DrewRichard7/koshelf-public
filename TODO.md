# KoShelf roadmap

This file lists open work. When an item ships, move it to [CHANGELOG.md](CHANGELOG.md).

## Features

- [ ] **Cross-platform app and in-app updates.** A standalone app on macOS and Linux that updates itself when the user asks, without a new disk image download each time. Updates stay manual and opt-in. See [the plan](docs/cross-platform-and-updates.md).
    - [ ] Phase 1: make the core run on Linux. Already done: the shared state folder, the launcher's one-time browser link, and the converter running with a warning. Still to do:
        - [ ] Test Kindle detection with a real Kindle (`mounted_volumes` looks under `/media/$USER` and `/run/media/$USER`).
        - [ ] Eject on Linux, for example with `udisksctl` (`device_info` and eject are macOS-only).
        - [ ] The Mac-and-Kindle library switcher, which `sync_connection` turns on only on macOS.
        - [ ] Sandbox the Kindle converter, for example with bubblewrap or Landlock. Until then, Send to Kindle on Linux runs it unsandboxed with a warning.
        - [ ] Hide macOS-only features, such as Apple Books and the iCloud Drive folder picker, where they don't apply.
        - [ ] Run the test suite and `scripts/check-service.py` on Linux.
    - [ ] Phase 2: settle the browser version and the supported platforms.
    - [ ] Phase 3: prototype and choose the shell (Tauri, or Sparkle as the fallback).
    - [ ] Phase 4: move the macOS app to the chosen shell.
    - [ ] Phase 5: ship manual, signed updates.
    - [ ] Phase 6: ship the standalone Linux app.
- [ ] **Sync with the Records project.** Identify which book and reading records to share, and decide how updates should flow between the projects.
- [ ] **Author and award-tag cleanup.** Suggest author aliases and cleanup of award labels.
- [ ] **Three-way library review.** Include the connected Kindle in the Mac and iCloud Drive review, so all three libraries are reviewed in one run. Verify the iPhone-to-Kindle workflow.
- [ ] **MTP Kindle delivery.** Explore USB delivery on macOS to Kindle models that use MTP instead of mounting as a drive.
- [ ] **Set reading progress manually.** Let the book details set a reading percentage, not only a status, so progress from reading elsewhere can win the next sync.
- [ ] **Import EPUBs from Apple Books.** Bring EPUBs you added to Apple Books, but not to KoShelf, into the Mac library. Books stores them unpacked in iCloud Drive, so KoShelf must download each one and repackage it. Books bought from Apple's Book Store are protected by DRM and stay out of scope.
- [ ] **KOReader progress on Mac and iPhone.** Look into syncing progress with KOReader on other devices, for example through KOReader's progress sync server.
- [ ] **Selective sync.** Let a sync review skip individual changes or whole categories (copies to Mac, copies to Kindle, replacements, reading statuses, folder removals), so applying a review isn't all or nothing.
- [ ] **Wireless transfer (Wi-Fi or Bluetooth).** Sync with KoShelf without a cable when the Kindle is awake and nearby. This will likely be a KOReader plugin built in its own repository, with KoShelf providing the Mac side. When that repository exists, link it here.
- [ ] **Theme customization.** Let users adjust a theme, for example its accent color, or add their own palette. Built-in themes are generated by `scripts/build-themes.py`.

## Testing

- [ ] Test Kindle sync, eject, and Send to Kindle on a physical Kindle with the current release. They were last tested on a Kindle with pre-release builds of 1.2.0.
- [ ] Test the Intel build on an Intel Mac, if one becomes available.
